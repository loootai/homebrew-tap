# Homebrew tap for looot

This tap installs the [looot](https://looot.ai) command line tool. looot gives you one API and one token for 300+ data providers.

## Install

```sh
brew install loootai/tap/looot
```

Check that it works:

```sh
looot --version
```

## Update

```sh
brew update
brew upgrade looot
```
